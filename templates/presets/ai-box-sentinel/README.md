# AI 节能盒子 + AI 哨兵示例预设

这是一份可迁移的脱敏样例，保留已确认的节点、阈值、字段口径和跨台账联合身份规则，不含真实客户、凭证、`file_id`、`base_token` 或 `table_id`。

业务把顶层 README 的唯一指令发给 Agent 后，Agent 应当：

1. 复制这两份示例到运行目录的 `followup/config/`，去掉 `.example`。
2. 一次只问一个业务问题，补齐台账地址、子表、责任范围和凭证。
3. 如字段名不同，参照 `field-map.md` 改配置，不改 Python 代码。
4. 先跑离线配置检查，再联网只读自检，最后只读演练。业务明确回复「确认通过」前不发送、不写提醒、不创建自动化。

接飞书多维表格需要 Node.js + `lark-cli` 并完成授权；本程序不会自动安装。
