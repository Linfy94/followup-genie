# 腾讯文档接入（从零安装）

这条线只有一个凭证：`TENCENT_DOCS_TOKEN`。它不是浏览器登录态，也不是文档链接；
程序不会读取浏览器 Cookie，更不会代替业务登录。

## 先确认谁来授权

用来扫码的腾讯文档账号必须已经能在浏览器中打开目标台账。若台账属于其他人，先让作者把
**这个扫码账号**加为可查看协作者；不要让作者去加“项目跟进精灵”或群机器人。

## 第 1 步：取得只用于本机的 Token

1. 用上面的账号登录 `docs.qq.com`，打开任意腾讯文档。
2. 进入「更多操作 → 开放平台 → OpenClaw 专用入口」。
3. 按页面提示扫码，取得 Token。
4. 只由安装助手写到 `<运行时目录>/.env`：

```text
TENCENT_DOCS_TOKEN=<扫码得到的值>
```

Token 相当于钥匙：不粘贴到聊天、截图、Git、配置文件或群消息中。更换扫码账号、Token
失效或撤销授权后，必须重新取得 Token；不需要安装任何命令行工具。

## 第 2 步：从链接取得两个定位字段

以 `https://docs.qq.com/sheet/Dxxxxxxxx?tab=ABC123` 为例：

| 配置项 | 填什么 |
|---|---|
| `file_id` | `Dxxxxxxxx`，即 `/sheet/` 后、`?` 前的一段 |
| `sheet_id` | `ABC123`，即 `tab=` 后的一段 |

不要把完整链接填进 `file_id`，也不要把 Token 填进配置 JSON。

## 第 3 步：只读探针

先运行 `doctor.py`，再按 `docs/接一条新业务线.md` 的只读示例读取子表列表。只有能看到
目标台账名称、子表 ID 和项目数，才继续写规则配置。腾讯文档会在读取前后核对最后修改人、
最后修改时间；变化即停止使用。

## 错误只按当前这一项处理

| 看到的现象 | 原因 | 唯一处理动作 |
|---|---|---|
| 缺 `TENCENT_DOCS_TOKEN` | 本机没有凭证 | 按第 1 步扫码；不要去登录命令行工具 |
| HTTP 401 / 403 | Token 失效，或扫码账号没有该台账权限 | 确认扫码账号能打开目标台账；能打开则重新扫码，不能打开则请作者给**该账号**查看权限 |
| 文件不可访问 / 工具业务错误 | `file_id` 错，或扫码账号没有文件权限 | 先重新核对 `/sheet/` 后的 `file_id`；正确仍失败才处理文档协作者权限 |
| 找不到 `sheet_id` | `tab=` 取错，或子表被改名/删除 | 先用只读探针列出当前子表，再更新 `sheet_id` |

不要把“重新扫码”“加协作者”“换链接”同时都做一遍。一次只修当前报错所指的一层。
